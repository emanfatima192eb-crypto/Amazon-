# Amazon Clone Website

## Project Description
This project is a clone of the Amazon website homepage, developed using HTML and CSS. It replicates the basic layout and design of Amazon's homepage.

## Technologies Used
- HTML5
- CSS3

## Features
- Main Navigation Bar
- Secondary Navigation Panel
- Search Bar
- Hero Section
- Product Category Boxes
- Product Images
- Footer Section
- Copyright Section

## Project Structure
- `index.html` – Website structure
- `style.css` – Website styling
- `Images/` – Project images and logo

## Purpose
The purpose of this project is to practice HTML and CSS skills by creating an Amazon-style e-commerce homepage.
